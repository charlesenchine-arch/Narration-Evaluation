# 大模型家族审美偏好与人类判断偏差实验协议 v4.0

更新日期：2026-09-13

## 研究结论边界

本研究检验两件事。第一，大模型作为评审时，是否在控制人类共识质量后，仍额外偏好自己或同一模型家族生成的中文叙事。第二，大模型的相对质量判断是否系统偏离人类判断。这里的“审美偏好”指可重复、可量化的排序倾向，不等同于模型具有人类式主观体验。

本协议不要求人类把各家族文本评成完全相同。若人类本身认为某个家族写得更好，模型对该家族的偏好可能只是正确识别质量。只有模型偏好超过人类基准，或在按人类质量匹配后仍存在稳定的家族效应，才能称为模型特有的审美倾向。

## 核心研究问题

### 研究问题一 模型是否偏好自己的输出

同一个评审模型是否比人类更偏好由它自己生成的文本。精确自偏好只作诊断，因为模型可能识别自己的固定措辞或模板。

### 研究问题二 模型家族是否共享偏好

同一家族的多个评审模型是否都额外偏好该家族中其他模型生成的文本。主检验排除“评审模型评价自己亲自生成的文本”，只保留跨模型的同家族比较。例如，Qwen 家族评审模型 A 对 Qwen 家族生成模型 B 的文本是否有超出人类基准的偏好。

### 研究问题三 机器判断是否偏离人类

模型对文本两两优劣的判断，与独立人类盲评共识相比偏离多少；这种偏离是否超过普通人类评审之间的分歧范围。

### 研究问题四 个体与家族效应能否区分

一个模型的偏好是否跨题目稳定，同一家族模型之间是否比跨家族模型更相似。稳定的模型内偏好支持“个体评审倾向”，家族内相关高于家族间相关才支持“家族共享倾向”。

## 总体实验结构

核心实验只要求候选文本由不同模型根据同一写作任务独立生成。人类在本研究中主要担任评审，不必为每个题目另外写作。这样可以直接检验不同机器评审如何评价同一批机器文本，也显著降低人类文本招募和版权负担。

实验分为两个互不混淆的部分。核心家族偏好实验使用同一 Prompt 下的机器文本，人类和机器都完成两两比较；只有这一部分进入家族偏好的确认性估计。人类文学锚点实验另行加入名著或其他高质量人类文本，用来检验机器与人类在高质量文学上的判断偏差。锚点实验不被解释为严格的同 Prompt 因果对照，也不进入核心家族偏好系数。

每个核心题目包含一个短篇写作任务和四篇来源隐藏的候选文本。预实验可采用两个家族、每家族两个生成模型；主实验再扩到四个生成家族。四篇文本形成六个无重复 pair。人类参与者每次只比较其中一对，机器评审对六个 pair 全部完成位置互换复测。两种评审使用完全相同的 pairwise 观测单位，因此无需把整组排序拆成相关性很强的伪独立样本。

## 模型家族与模型选择

### 家族定义

家族按基础模型谱系定义，不只按产品品牌定义。使用其他家族底座蒸馏得到的混合谱系模型不能用于确认性家族检验，只能放入探索性分析。例如，以 Qwen 为底座的其他品牌蒸馏模型不应被简单归入独立家族。

正式实验选择四个生成家族，其中至少两个为可本地复现的开放权重家族。每个重点评审家族至少选择两个不同规模或版本的模型。模型名单、权重哈希、API 版本、模板、量化方式和采集日期必须在生成前冻结。论文中使用“开放权重”而不是笼统的“开源”，因为部分模型采用自定义模型许可证。

### 角色分离

每个家族设置生成模型槽位和评审模型槽位。同一模型可以同时承担两种角色，但确认性“家族偏好”结果必须来自不同模型之间的交叉评价。完全相同模型对自身文本的评价单列为 exact self preference，不与 family preference 合并。

### 冻结的预实验配置

现有服务器为 8 张 H100 80GB。预实验先做两个可复现的开放权重家族，不为了凑数量引入中文能力明显不足的模型。

- Qwen 生成模型：Qwen3 14B 与 Qwen3 32B，统一关闭 thinking。Qwen 评审模型：Qwen3 8B、14B、32B。确认性 Qwen 家族效应排除生成与评审为同一个 checkpoint 的格子。
- GLM 生成模型：GLM 4.5 Air 与 GLM 4.7 Flash。GLM 评审模型使用这两个不同版本交叉评价，确认性效应同样排除 exact self。
- 每个 Prompt 产生四篇文本，即两个 Qwen 与两个 GLM。生成模型和显示位置按题目平衡轮换。
- 所有模型统一采用无搜索、无工具、非思考或可用的最低推理设置。模型无法关闭思考时，不放入这一主组，而作为单独消融条件。

### 主实验扩展配置

- 在预实验管线稳定后，增加 DeepSeek V3 系列与 Kimi K2 Instruct 或 Kimi K2.5 Instant 作为第三、第四生成家族。两者均有开放权重，但标准部署规模远大于本地 Qwen 与 GLM 组；可采用官方 API 或单独准备的量化部署，不能把第三方路由返回的未知版本当作可复现实例。
- Qwen 与 GLM 是第一轮家族归因的确认性主组，因为每个家族都有多个不同模型。DeepSeek 或 Kimi 如果只有一个可核实版本，只能作为单模型或生成来源结果，不能声称整个家族存在偏好。
- Llama、Mistral 等非中文主导模型可在外部有效性实验中加入，但不建议为了扩大名单放入中文文学主实验，以免把中文能力差异误写成审美差异。
- 以 Qwen 为底座的 DeepSeek 蒸馏模型等混合谱系模型单独标记 lineage，只参与一致性分析，不参与独立家族归因。

## 题库和文本生成

### 题库规模

预实验使用 24 个写作任务。确认性主实验以 120 个任务为起点，并根据预实验得到的 prompt 间方差做功效模拟后冻结最终数量。题目覆盖现实、悬疑、科幻、成长、情感、寓言等体裁，各体裁数量平衡。

### 文本长度

候选文本限制为 450 至 650 个中文非空字符，目标长度为 500 字；同题四篇之间的最大长度差不超过 20%，并在统计中继续控制实际长度。500 字足以形成基本人物、冲突、转折和收束，不再把实验限制为只有一个瞬间或一个反转的微型叙事。研究结论仍限定为短篇中文叙事，不能直接推广到长篇小说。

### 生成参数

- 所有模型关闭搜索、工具调用、记忆和外部知识库。
- 使用非思考模式或服务端允许的最低推理设置，不要求输出推理过程。
- 生成温度、top p、最大输出长度和系统提示在同一角色内固定。
- 每个模型对每个题目只保留预先规定的第一次合格输出，不按文学质量挑选。
- 仅当输出拒绝、截断、泄漏身份或超出长度范围时重试；重试次数和原因必须记录。
- 程序按非空字符重新计数，不接受模型自报字数。超出范围的文本按统一规则自动重试，达到上限后标记缺失。

### 候选组构造

每个题目展示四个候选家族，每个家族一篇。家族内具体生成模型按平衡轮换表分配，使每个模型出现在相近数量的题目中。题目、家族、模型、长度和位置的分配在看到人类或机器评分前生成并冻结。

预实验的两家族设计是例外：每题由 Qwen 和 GLM 各提供两篇，模型实例在题目间平衡。分析同时估计文本级、模型级和家族级效应，不能把同一家族的两篇文本当作独立家族。

## 人类文学锚点实验

### 作用与边界

名著节选代表的是经过出版与长期筛选的高质量人类文学，不代表普通人的平均写作水平。它们适合回答“机器评审和人类评审面对较高文学质量时是否发生系统分歧”，但不适合直接充当核心家族偏好的金标准。模型可能在预训练中见过名著，也可能通过人物、措辞或情节认出来源；原始作品也不是根据本实验 Prompt 创作。因此，名著锚点的结果必须与同 Prompt 机器家族实验分开报告。

### 锚点文本池

- 建立 40 至 60 篇人类文学锚点，每篇截取 450 至 650 个中文非空字符，目标 500 字。
- 只选能够独立理解、包含具体行动或心理变化、结尾不在半句话处的完整段落。不得人工润色原文；仅规范空格、繁简体和明显扫描错误，并保留原文哈希与修改日志。
- 高质量层优先使用版权状态清楚的现代白话作品，例如中文维基文库或 Project Gutenberg 中明确标记可用的鲁迅、郁达夫及其他早期现代作品。正文不展示书名和作者，但数据库永久保留署名、作品、发表年、章节、来源链接、许可或公有领域依据。
- 不全部采用最著名的标志性段落。优先选择作品中较少被引用但仍具独立叙事性的片段，以降低模型直接背诵和人类参与者识别的概率。
- 另设普通人类文本层，来自许可明确且有原始 Prompt 的写作数据或经授权征集。只用名著会造成“人类来源等于高质量”的完全共线，无法观察高质量机器文本与普通人类文本的交叉区域。
- 古代文言、章回体和当代白话不得混为一个总体。第一轮只使用现代白话；古典文学作为单独的文体外推实验。

### 与机器文本的匹配

研究者可从锚点提炼不泄漏人物姓名、独特情节、结局和标志性措辞的宽泛写作说明，再让各生成模型独立写作 500 字文本。该说明属于 reverse Prompt，配对只能称为题材、体裁和长度匹配，不能称为作者与模型接受了同一个原始 Prompt。

人类和机器评审均采用同一两两比较界面，分别比较人类锚点与机器文本。主要统计量是某评审相对于人类共识的“额外机器偏好”或“额外人类偏好”。名著高质量层、普通人类层和纯机器同 Prompt 层分别估计，不把三者合并成一个来源系数。

### 识别与记忆控制

偏好判断完成后另发一个独立识别请求，询问评审模型是否能给出作品名或作者，并记录答案与置信度。明确识别的样本单列或排除后复算；同时报告知名段落与冷门段落的分层结果。模型回答“不认识”不能证明没有潜在记忆，因此名著实验始终作为外部锚点和压力测试，而不是严格的因果证据。

## 人类盲评设计

### 单人单题链接

参与者打开链接后只完成一道正式两两比较题。页面先显示简短说明，再显示写作任务和两篇匿名候选文本。参与者选择 A 更好、B 更好或难分高下，并填写信心度。提交后任务结束，可自愿点击“再做一题”，但服务器仍把每次分配视为独立任务并记录匿名参与者标识，以便在统计中聚类。

把文本扩到约 500 字后，一次展示四篇相当于要求普通参与者阅读约 2000 字并维持四项工作记忆，容易产生位置、疲劳和草率排序。两两比较把一次阅读量控制在约 1000 字，也与机器评审的观测单位完全一致。四篇整体排序只保留为小规模任务形式消融。

一人只做一题能降低招募阻力，但无法用重复题检测个人一致性。因此，质控依靠最低合理阅读时间、页面焦点时长、是否读完两篇、回答是否完整、一道简单的说明理解题，以及同一设备短时间重复提交检测。IP 只保存不可逆哈希，不保存明文。

### 随机分配

服务器从未达到目标样本数的 pair 中按缺口加权抽样。A B 标签和左右顺序对每位参与者重新随机。来源家族、模型名称和采集方式永不显示。每个 pair 收满配额后停止分配。

### 样本量

预实验每个 pair 先收 8 份有效判断。24 个 Prompt、每题 6 个 pair，共需要 1152 份单题提交。确认性主实验暂按每个 pair 12 份有效判断估算；120 个 Prompt 共需要 8640 份单题提交。最终样本量不根据观察到的显著性临时增减，而是在预实验后用分层模型模拟功效并结合实际招募转化率一次性冻结。

### 人类共识

使用分层 Bradley Terry 模型估计每篇文本的潜在人类效用和每一对文本的胜率；tie 使用 Davidson 扩展或预注册的半胜处理。若同一参与者自愿完成多题，标准误按参与者聚类。

人类可靠性报告平均 pairwise agreement、分半共识相关、不同参与者子样本间的排名相关和每题后验不确定性。near tie 定义为人类胜率置信区间覆盖 0.5 或位于预注册的中性带内，并与明确偏好题分开报告。

## 机器评审设计

### 两两比较作为主任务

开放权重和闭源模型都使用同一套两两比较协议。四篇候选文本形成六个无重复 pair，每个 pair 以 A B 和 B A 两种顺序各评一次。每次请求只包含原写作任务、两篇匿名文本和冻结的总体叙事质量准则，输出 winner、tie、confidence 的结构化 JSON。

两两比较比一次给四篇打分更适合作为主实验，因为它避免不同模型评分尺度不可比，并减轻约 2000 字上下文、首位偏差和一次性排序错误。四篇整体排序只作为消融，用来测量任务形式是否改变结论。

### 推理与重复

评审关闭搜索和工具调用，使用非思考模式或最低推理设置，temperature 设为零或服务允许的最小值。若模型在相同输入下仍有随机性，预实验测三次重复的一致性；主实验根据该结果决定是否保留单次或三次重复。任何模型都不要求展示思维链，只保留简短可公开理由作为次要分析。

### 机器评审数量

每个重点家族至少两个评审模型。预实验若使用八个评审模型，则判断次数为 24 题乘六个 pair 乘两个位置乘八个模型，共 2304 次。主实验在功效和费用核算后冻结模型数量；本地开源模型优先跑完整矩阵，闭源模型可以先跑预注册的代表性子集，但不得只报告显著模型。

## 主要统计模型

### 人类调整后的来源偏好

对评审模型 j 比较文本 a 与 b，拟合以下分层逻辑模型：

`logit P_j(a>b) = alpha_j + beta_j logit P_H(a>b) + gamma_j(source_a) - gamma_j(source_b) + order + prompt random effect`

其中 `P_H` 是独立人类盲评得到的胜率。`gamma_j(source)` 表示在控制人类共识后，评审模型 j 对某一生成家族的额外偏好。也可以在质量匹配子集上直接计算模型胜率减去人类胜率，作为更直观的 excess preference percentage points。

为避免用同一批人类评分既挑选近似同质量 pair 又验证偏差，采用交叉拟合。人类排序随机分成 selection half 和 confirmation half；前者只用于定义质量匹配或 near tie，后者用于估计最终偏差。两半轮换后合并估计。

### 自身偏好

精确自身偏好定义为评审模型对由同一个模型实例生成文本的额外偏好。该指标单列，不能证明家族共享审美。

### 家族偏好

评审家族 J 对生成家族 S 的偏好矩阵以人类调整后的 excess preference 表示。自家族效应定义为：

`FamilySelfBias_J = Bias(J to J) - mean Bias(J to non J)`

确认性估计排除完全相同的生成与评审模型，只保留同家族跨模型评价。使用分层模型估计家族均值和模型间方差，并按 prompt 分组 bootstrap 计算置信区间。

### 机器与人类偏差

将人类评分分成两个互不重叠的半样本。用半样本一形成共识，再分别计算半样本二和各机器评审与该共识的 pairwise agreement、Brier score、log loss 和 Kendall tau。机器结果只有低于人类到人类基线置信区间时，才能称为明显偏离人类。

## 确认家族共享倾向的标准

必须同时满足以下条件，才使用“家族共享审美倾向”这一表述：

1. 家族层面的自家族效应置信区间排除零，且绝对效应达到预注册的实际意义阈值。
2. 至少两个该家族评审模型的效应方向一致。
3. 排除完全相同模型的自身文本后，跨模型同家族效应仍成立。
4. 在题库随机分半、体裁分层和生成模型 leave one out 中方向稳定。
5. 调整长度、位置、题材、人类胜率和拒答重试后，效应仍存在。
6. 多个家族检验使用 Holm 校正，不能只选择显著家族报告。

预注册建议把五个百分点的 excess preference 设为最小实际效应。若置信区间跨过零，只能报告证据不足；若整个置信区间落在正负五个百分点内，可以报告在该精度下未发现有实际意义的偏好。

## 人类无来源偏好的强结论

“人类对各家族评价差不多”必须用等效性检验支持，而不能用 p 大于 0.05 代替。对每个生成家族估计人类调整前的平均胜率，并检验家族差异置信区间是否全部落入预注册的正负五个百分点等效区间。

如果人类确实无明显家族偏好，而某一机器评审家族出现稳定自家族效应，这是最容易解释的证据。如果人类认为某些家族质量更高，研究仍可继续，但主结论必须依据人类调整后的剩余偏好，而不能比较原始平均分。

3. 家族偏好热图，行是评审家族，列是生成家族，单元格为控制人类质量后的 excess preference。对角线显示自家族效应。
4. 家族模型森林图，显示同一家族不同评审模型的效应方向和置信区间。
5. 位置一致性表，报告 A B 与 B A 换序后的矛盾率。
6. 题材和长度分层结果，检验偏好是否只来自某种文体或长度。

## 分阶段执行

### 阶段零 管线冒烟测试

使用 4 个题目、Qwen 与 GLM 各两个生成模型和少量评审模型，只验证 450 至 650 字控制、盲化、pair 配额、位置随机化和分析脚本。该阶段不报告科学结论。

### 阶段一 偏差预实验

使用 24 个题目、每个 pair 8 份有效人类判断，以及 Qwen 和 GLM 的多个评审模型。目标是估计 Prompt 间方差、人工完成时长、人类共识、位置偏差和本地推理成本，并决定主实验功效参数。所有统计为探索性结果。

### 阶段二 确认性主实验

冻结题库、模型表、生成参数、排除规则、统计代码和最小效应。建议以 120 个 Prompt、每个 pair 12 份有效人类判断做初始功效预算。先完成并锁定人类数据，再解盲来源并运行机器评审分析。

### 阶段三 外部有效性

先加入 40 至 60 篇约 500 字的人类文学锚点，再加入有原始 Prompt 的授权人类写作、长文本、英文或其他语言，以及未见模型家族。该阶段回答结论能否推广，不与核心家族偏好主实验混在一起。

## 在线链接的数据与接口要求

每个候选文本记录 `prompt_id`、`text_id`、`source_family`、`source_model`、`generation_role`、`length_chars` 和生成配置。私有映射表保存来源，公开评分接口只返回盲化后的 session label 和文本。

每次人类提交记录 `assignment_id`、匿名参与者哈希、题目、pair、随机显示顺序、winner 或 tie、信心、开始时间、两篇滚动状态、页面焦点时长和质控状态。参与者页面不接收任何来源字段，避免通过浏览器开发工具泄漏来源。

服务端需要原子配额分配、重复提交防护、断点恢复、导出 JSONL、实时完成量统计和停止开关。分析前导出冻结快照并保存哈希。

## 排除规则

- 文本不在 450 至 650 个非空字符范围，或同题长度差超过 20%。
- 文本包含模型自称、生成说明、标题外的字数报告或明显拒答。
- 生成过程使用搜索、工具或后续人工润色。
- 人类选择缺失、未通过说明理解题，或阅读时间低于预实验冻结阈值且同时出现其他异常信号。
- 机器输出无法解析，先按同一请求重试一次；仍失败则记为缺失，不把失败改成不利排名。
- 主实验开始后不得根据评分结果删除“写得不好”的候选文本。

## 结论措辞

若证据成立，允许写：“在本协议的短篇中文叙事中，若干评审模型在控制人类共识质量后，仍对同家族其他模型生成的文本表现出稳定的额外偏好。”

不允许写：“大模型拥有独立审美”“某家族天然更懂文学”或“机器与人类审美完全不同”。未观察到偏差时，应报告效应上界和等效性区间，而不是把不显著结果解释为绝对无偏。
