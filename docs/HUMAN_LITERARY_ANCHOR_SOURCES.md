# 人类文学锚点候选来源 v1

更新日期：2026-09-13

## 用途

本清单用于构建 40 至 60 篇、每篇 450 至 650 个中文非空字符的人类文学锚点。锚点只进入“机器与人类判断偏差”的外部实验，不进入同 Prompt 的模型家族偏好主效应。

第一轮不使用《阿 Q 正传》《狂人日记》《祝福》等最常见课本段落。它们可以作为“高识别风险层”保留，但不能和较冷门段落混合后只报一个总体结果。

## 抽样规则

1. 每个作者最多贡献锚点总数的 25%，避免把作者风格误当作人类风格。
2. 每篇作品最多抽取两个不重叠片段；同一情节不得切成多个样本。
3. 片段必须在 450 至 650 个非空字符之间，目标 500 字，并能在不阅读上下文时理解主要人物、行动和变化。
4. 不删除作者原有句子来凑长度，不补写过渡句，不把多个远距离段落拼接成一篇。允许统一空白、标点宽度和繁简体，但必须保存原文与规范化文本的双重哈希。
5. 数据库保存作者、作品、篇目、发表年、章节或段落定位、来源 URL、抓取时间、页面固定版本、版权标签、规范化操作和识别风险层。
6. 评审界面隐藏作者和书名；论文与公开数据说明恢复署名和来源。不得因为盲评而永久删除作者信息。
7. 每个锚点在偏好评审后单独运行模型识别探针；能够正确说出作者或作品的样本进入 recognized 分层。

## 仍需补充的普通人类层

名著只能提供高质量锚点。为获得人与机器质量分布的重叠区，还需加入许可明确、最好保留原始写作 Prompt 的普通人类短篇。现有 COIG Writer 候选可用于筛查，但发布前仍要核对数据库许可是否覆盖单篇内容；STORAL 没有清楚的数据集级许可，只能暂作内部审核，不进入公开数据。

## 版权审计底线

中文维基文库要求作品在相关法域属于公有领域或具有兼容授权，并强调作者署名等精神权利。中华人民共和国著作权法规定自然人作品的相关财产权一般保护至作者死亡后第五十年的 12 月 31 日，署名权、修改权和保护作品完整权的保护期不受限制。研究发布前仍需按具体作品、版本和发布法域逐项复核，本清单不替代法律意见。
