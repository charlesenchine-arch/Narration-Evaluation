# 论文大纲（草稿 v0.1，2026-08-14）

> 主线：**解耦性实证发现**——评估器的"像人分"与文本"质量"是两个正交维度，用评估者图灵测试验证"像人"。
> 本大纲填充已完成的证据；标 ⏳ 的为待数据/待实施。

---

## 题目（暂定）
《像人但不评判质量：一个解耦的中文叙事像人评估器及其图灵测试验证》
（英文备选：Human-Like but Not Judgmental: Decoupled Human-Likeness Scoring for Chinese Narrative and an Evaluator Turing Test）

## 摘要（骨架）
1. 叙事生成需要"像人类评委"的 reward，但"像人"与"质量"常被混淆。
2. 我们构建三视图像人评估器（判别器+表示+属性），实证发现两个维度**正交**：像人分能判断"像不像人"（区分 H/G AUC≈0.99），对"好不好"一无所知（H 内高低质 AUC≈0.47）。
3. 长度偏置消除、注水攻击防刷、跨寄存器/跨生成器稳健。
4. 评估者图灵测试验证判断像人（⏳）。

---

## 1. 引言
- 动机：叙事时间 Transformer（Track A）需要 reward；reward 要"像人类评委"，不是"最准检测机器"。
- 核心命题：**像人分与质量分是正交维度**（用户反复强调：目标是像人，不是最准）。
- 贡献：
  - 三视图像人评估器设计（可解释属性 + 判别 + 表示）
  - 解耦性实证：区分度分离 + 正交性 + 长度偏置控制 + 防刷分
  - 跨寄存器/跨生成器稳健性（DeepSeek vs Qwen）
  - 评估者图灵测试协议（⏳）

## 2. 相关工作
- 机器文本检测（SemEval-2024 Task 8 / RealDet / HWT）
- 生成 reward 模型（RLHF reward model）
- 图灵测试与"像人"评估（Human-like Text…，见参考文献 PDF）
- 位置：既有工作把"像人"当"高质量/可读"的代理，我们证明二者正交。

## 3. 评估器设计
- 三视图：`S_disc`（MacBERT 判别器 P(human)）+ `S_repr`（bge 向量到 H 参照集相似度分位）+ `S_attr`（11 属性马氏距离）
- 长度严苛度：`final = like^κ`，κ 随长度；**长度匹配判别器**消除长度偏置（G 上 Spearman 长度偏置 +0.178→+0.001）
- **B1 加固**：S_repr/S_attr 窗口化（前 400 字符）+ α=0.5 → 轻注水攻击 +65%→+0%
- 数据：自建集 600（H300 / G_ds100 / GZ100 / 锚定100），第二生成器 Qwen 200（flash+3.7）

## 4. 解耦性实证
### 4.1 数据与质量分来源
- 质量分：LLM-as-Judge（DeepSeek，600/600 成功，锚定校验 AUC=1.000）+ 人类评分（⏳ 收集中）
- 像人分：评估器输出；人类像人感知（⏳ 滑块收集中）

### 4.2 正交性（核心）
- H 内 Spearman **-0.246**（p<0.001）；G 内 ≈0（G_ds +0.097 / qwen-flash +0.028 / qwen3.7 -0.154 / GZ -0.185）
- 判别器对 H 内低质文本打更高像人分（LLM 分 2/3/4 → 像人分 0.766/0.752/0.713 单调）——系统性模式，**如实呈现**

### 4.3 区分度分离
- 像人分区分 H vs 各生成器 AUC 0.993–1.000（跨 4 个生成器批次）
- 像人分区分 H 内高低质 AUC≈0.47（≈随机）→ 对"好坏"一无所知

### 4.4 长度偏置控制
- n-gram → MacBERT：G 内像人分 vs 长度 -0.562 → +0.070；注水虚涨 0.20→0.41 → 0.007

### 4.5 防刷分（B1）
- 三种注水（append_filler / interleave / self_repeat）× 1.5x-3x；加固后全堵，Spearman(final,len)=-0.859
- 窗口化不伤 H 自然长文（-15.7% → -11.1%）

### 4.6 稳健性：跨寄存器 + 跨生成器
- 章回 GZ 区分 AUC=1.000；GZ 内 -0.185（弱负，如实报告）
- 真·第二生成器 Qwen（flash + qwen3.7）：H vs Qwen AUC 0.993/1.000；生成器内 ≈0（批次噪声）

### 4.7 锚定校验
- 极好/极差锚定，LLM judge 尺度有效（AUC=1.000）；人类侧 ⏳

## 5. 评估者图灵测试（⏳ 数据依赖）
- 协议见 `docs/evaluator_turing_test_protocol.md`：S1 一致性（vs 人类-人类基准）+ S2 ABX 判别 + S3 方向性
- 数据：人类像人滑块（0-100）+ 评估器像人分

## 6. 讨论与限制
- H 内负相关 -0.246：可能反映 n-gram 残余或 LLM 分偏差，需进一步研究
- 跨生成器正交性批次噪声（qwen3.7 -0.154 ns）：方向稳定、强度波动
- 域漂移：构造证据（抒情/技术文）失败，A3 搁置
- 真人质量分尚未到位；LLM-as-Judge 是初步基线

## 7. 结论
- 像人评估器可判断"像不像人"、对"好不好"无偏 → 适合作为"像人"reward，与质量信号解耦使用。
