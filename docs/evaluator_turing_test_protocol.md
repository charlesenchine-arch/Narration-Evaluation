# 评估者图灵测试协议（草案 v0.1，2026-08-14）

> 目的：验证论文主claim——评估器的"像人分"对文本的判断/排序**像人类评委**（不是"机器检测最准"，而是"判断像人"）。
> 与本项目已有证据的关系：解耦主线（像人分⊥质量分）已完成实证，本协议是"像人"侧的最后一块验证。

---

## 1. 两个必须先避开的坑（设计前提）

**坑 1：正交性陷阱。** 已实测像人分与质量分正交：H 内 Spearman **-0.246**、G 内 ≈0（qwen-flash +0.028 / qwen3.7 -0.154 / GZ -0.185）。
因此**不能用"评估器像人分 vs 人类质量分"直接做对比**——那既测的不是"像人"，而且按解耦结论它们本来就不该相关。
⇒ 图灵测试必须让**人类也产出"像人感知"判断**（"这篇读起来像人类写的吗"），作为评估器判断的对照系。

**坑 2：H/G 混淆。** 像人分区分 H/G 的 AUC≈0.99+，裁判看着文本内容就能猜来源。
⇒ 判别式测试必须**在寄存器内**进行（只在 H 内、只在 G_ds 内、只在 G_qwen 内），否则测的是"机器文本可分性"而非"评估器像不像人"。

---

## 2. 需要的新数据：人类"像人判断"

评分平台当前只收**质量分**（1-5 趣味量表 + 评语）。图灵测试需要每篇多一个维度：

> **像人滑块**："这篇读起来像人类写的吗？"（0-100 滑块，或 1-5 量表）
> 指令必须明确与质量分区分开：不是"好不好"，是"像不像人写的"。

实施选项：
- **A（推荐，2026-08-14 已实施）**：在现有评分页每篇追加一个像人滑块（已改 `rating_frontend.html` + `rating_server.py`），评委同批顺手填，成本几乎为零（每篇多 5 秒）。滑块 0-100、拖动确认后生效，存储于 `rating_state.json` 的 `likes` 字段，`/api/summary` 输出 per-item `like_mean`。
- **B**：独立"像人判别"小问卷：给文本，强制二选一"人类写的 / 机器写的"+置信度。更接近经典图灵测试，但要额外组织一批评委。

已选 A：复用同一批质量分评委，工作量仍维持每篇 10-20 条。

**收集要求**：每篇 ≥2-3 个像人判断（与质量分同批）；样本 held-out 60-100 篇，**按寄存器分层**（H / G_ds / G_qwen），并包含极好/极差锚定作为正负对照。

---

## 3. 统计设计

### S1 · 一致性（主检验）
- 评估器像人分排序 vs 人类像人判断**均值**排序的 Spearman。
- **基准**：同一批文本上人类评委两两之间的 Spearman（人类-人类一致性上限）。
- 判定：评估器-人类一致性落在人类-人类一致性的置信带内 ⇒ "像人"成立。

### S2 · 判别（图灵 ABX，可作主/次检验）
- ≥10 名裁判，每人 K 组三元组：(文本, 判断 A, 判断 B)，其中一个是真人像人判断、一个是评估器像人分（校准到同一量纲后呈现，**不显示来源**）。
- 裁判答"哪个是真人给的？"。检测率 ≈50% ⇒ 通过。
- **逐寄存器报告**（规避坑 2），另加锚定组作尺度校验。
- 统计：二项检验 H0: p=0.5；K=20、裁判 10 → 200 判断。

### S3 · 方向性（可选，诊断用）
- 若裁判能区分，看是否有系统性偏好（真人判断是否整体更严苛/温和、或对某类文本更敏感）。
- 与 **LLM-as-Judge** 做参照：同一批文本上 deepseek 判断 vs 人类判断跑同样的 S1/S2，作为"机器判断像人"的既有基线（LLM 判断人类质量分已有 600/600 数据，可直接复用）。

---

## 4. 样本量估算
- S1：n≥50 时检测 ρ 差异 0.1（α=0.05, β=0.8）。
- S2：裁判≥10 × K=20，二项检验功效充分。
- 与 P0 人工评分共享评委与文本，边际成本低。

---

## 5. 实施步骤（数据到位后）
1. 评分平台加"像人滑块"（A 方案）——待确认后我改 frontend + server schema + 分配逻辑。
2. 收集到 ≥2-3 条/篇后，写 `scripts/turing_test_analysis.py`：
   - 加载人类像人判断均值 + 评估器 like-scores（部署配置 `default_deploy.yaml` 下计算）；
   - 输出 S1 Spearman + 人类基准 CI、S2 ABX 检测率（逐寄存器）、S3 方向性；
   - 与 deepseek LLM-judge 对照列。
3. 校准细节：评估器 like-score 与人类像人判断量纲不同，S2 呈现前把两者映射到同一标尺（分位校准）。

---

## 6. 风险与缓解
- 人类像人判断本身噪声大 → 多评委均值 + 报告人类-人类一致性。
- 评委可能把"像人"和"质量"混为一谈 → 指令给锚定样例校准（极好锚定是 H 高质量、极差锚定是 G 低质）。
- 评委工作量增加 → 每篇仍 10-20 条可接受；也可拆两条链接分别收质量分/像人分。
